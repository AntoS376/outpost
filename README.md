# Outpost

A self-hosted offline knowledge server for macOS: a library, an AI assistant, maps, notes and emergency tools that keep working with no internet, served from your Mac to the devices around it. Everything runs natively on the Mac; Docker is only needed for the optional Docker apps.

| Module | What it does | Powered by |
|---|---|---|
| Library | Read Wikipedia and other books offline | `kiwix-serve` |
| Assistant | Chat with a local model, optionally grounded in your documents | Ollama, LM Studio or llama.cpp |
| Maps | Browse downloaded regions, carve out your own, search for places, choose the map colours | PMTiles, MapLibre |
| Education | Courses, videos and exercises (optional) | Kolibri |
| Notes and tools | Markdown notes, calculator (standard and scientific), unit converter, encoders, checksums, JSON, password generator; CyberChef (optional) | built in, CyberChef |
| Games | Klondike, FreeCell and Spider solitaire, Sudoku in four levels, Minesweeper, Mahjong tiles, Nonograms and Word search | built in |
| Directions | Turn-by-turn routes by car, on foot or by bike on Outpost's own map | OSRM, osmium |
| Emergency | Network SOS with alarm, sound/light/Morse signals, first aid, location formats, emergency card, kits | built in |
| Voice | Short voice messages on one shared channel: hold to talk from Home, the Voice page or any page; new messages play by themselves, kept 24 hours | built in |
| Documents | Upload files for the Assistant to answer from | built in, PDF.js |
| Preparedness and radio | Ready.gov guides kept as PDFs with a supply-kit checklist; radio channel cards (NOAA, FRS/GMRS, calling frequencies), your own channels and a check-in log | built in |
| Apps | Install, start and stop local web apps; optional Docker apps; installers for phones | built in, Docker (optional) |

## What's new in 2.0.0 (12 November 2026)

- **Voice messages.** A walkie-talkie that remembers: hold to talk, let go to send, and new messages play by themselves on every device with voice on. Messages stay 24 hours. Talk from the green **Voice channel** band on Home (under Emergency SOS), from **Be ready → Voice**, which also shows who is on the channel, or with the mic button in the corner of every other page.
- **A grouped menu.** The sidebar sorts every page under Know, Ask and find, Be ready and Keep, with SOS on top. On phones it becomes a bottom bar (Home, Library, Chat, Maps, SOS, More), and **More** slides up the rest.
- **Outpost as an app.** Add it to an iPhone, iPad or Android home screen, or to the Mac's Dock, and it opens in its own window with the cream lookout-tower icon. The join page and the setup guide show the steps.
- **Better on iPhones.** The join page checks whether the phone really trusts Outpost's certificate and says what to fix. The top and bottom bars keep clear of rounded corners and the home indicator.
- **Place names on maps.** An admin clicks **Install map fonts** under Maps → Your maps, and town and street labels appear, offline.
- **Install buttons.** Kolibri (Education), CyberChef (Tools) and the map fonts install with one click, after the admin confirms the exact command. Progress shows as a percentage under Transfers.
- **One look.** The same pencil lookout tower is the logo, the browser tab icon (also at `/favicon.ico`) and the home-screen icon, and Home's header is the wordmark alone.
- **Sturdier setup.** Setup fetches kiwix-tools from official mirrors (checked by SHA-256) when download.kiwix.org is slow, and fetching map fonts no longer needs `git`. The suggested chat model is `llama3.2:3b`; each device remembers the model picked on the Assistant page.

## Look and feel

A field expedition manual: warm linen paper, off-white cards with a fine rule and a soft shadow, graphite-pine ink, terracotta for the SOS band, a deeper pine green for the Voice band, olive pine for running and stone gray for stopped. Headings use Space Grotesk in tracked capitals, body text Inter, and addresses and status tags JetBrains Mono. All three fonts are under the SIL Open Font Licence and are bundled into `public/vendor/fonts` at build time, so they work offline. The logo is the same pencil fire lookout tower that stands in the paper's top-right corner, drawn in green on cream with rounded corners and a faint edge (`badge-256.png`, used in the sidebar and on the sign-in and join pages; a close-up of the tower alone in `badge-64.png` for browser tabs). Home screens and the Dock get square versions: the cream pencil scene, unframed, filling the whole icon (iOS and Android round the corners themselves): `app-180.png` for iPhone and Mac, `app-192.png` and `app-512.png` for Android, and `app-maskable-512.png`, with the tower inside the safe zone, for Android's round or shaped icons. `public/manifest.webmanifest` names the app and lists them, so Outpost can be added to a home screen or the Dock and opens in its own window (steps on the join page and in the setup guide); Home's header is the wordmark alone, with the tower in the paper behind it. Home uses engraved pictures (books, map and compass, lantern, file folder) and solid icons (cap, notebook, wrench, people), all in `public/img` with transparent backgrounds; in the dark theme the pictures are inverted to light ink. Light and dark themes follow the system setting, or the **Auto / Light / Dark** switch in the top bar (remembered per device in `localStorage`; `public/theme.js` sets `data-theme` on `<html>` before the page draws, and the dark rules in `public/app.css` apply under `[data-theme="dark"]`, or under the system's dark mode unless `[data-theme="light"]`). Maps redraws in the matching colours, and the book reader on the content port gets the same choice through an `outpost_theme` cookie (cookies are per host, not port), which picks the matching `kiwix-skin.css`. Text meets WCAG AA contrast in both.

## Install

**New to Outpost?** Read the step-by-step [setup guide](docs/SETUP.md): installing, sharing with phones and computers with or without a router (an existing router, a travel router, the Mac's own Wi-Fi or a phone hotspot), and finding your location offline. The same guide is in the app under Home → Sharing → Setup guide.

**Easiest:** download **Outpost.zip** from the latest GitHub Release, unzip it and double-click **Install Outpost.command**. The first time, macOS blocks it: open System Settings → Privacy & Security and click **Open Anyway**. The installer offers to install [Homebrew](https://brew.sh) if it's missing, copies Outpost to `~/Applications/Outpost`, runs `scripts/setup-mac.sh` and opens Outpost in your browser. The same in one line:

```sh
curl -fsSL https://raw.githubusercontent.com/AntoS376/outpost/main/scripts/install.sh | bash
```

Make the release ZIP with `./scripts/make-release.sh` and attach it to a GitHub Release as `Outpost.zip`. To install from a fork instead, change `AntoS376` above and in `scripts/install.sh` to your own account (or set `OUTPOST_REPO`).

**From the code** — requires macOS, [Homebrew](https://brew.sh) and a terminal.

Keep the code out of your data folder. macOS disks ignore upper and lower case, so a copy of the code at `~/outpost` *is* the data folder `~/Outpost`. Put it somewhere like `~/Developer/outpost`; setup and the server refuse to run if the two folders overlap.

```sh
./scripts/setup-mac.sh                 # installs Node, Ollama, pmtiles, OSRM, osmium, kiwix-serve; builds; starts at login
./scripts/setup-mac.sh --pull-models   # also downloads the chat model llama3.2:3b and the embedding model
./scripts/setup-mac.sh --lan           # share on your network with a generated password
```

Then open <http://localhost:8080>. On first launch, with nothing installed yet, Outpost opens a setup wizard: make the admin account (while no account exists), choose whether to share on your Wi-Fi (it writes `OUTPOST_HOST` to the settings file and restarts the login service), pick a Wikipedia size (from 0.3 GB of short answers to 127 GB with every picture) and a level (Basic, Extended or Complete) for each of six topics (Health, Staying safe, Food and farming, Fixing and building, Learning, Computers and electronics), a world overview or an area of the map, and AI models; it shows the total against your free disk space and queues everything in Transfers. Skip it if you like; Home links back to it. Your data lives in `~/Outpost` (`zim`, `maps`, `notes`, `docs`, `rag`, `assets`, `bin`). To use another folder, set `OUTPOST_HOME` in `~/.config/outpost/env` before running setup.

Optional: map fonts, so maps show place labels. An admin clicks **Install map fonts** under Maps → Your maps (or runs `./scripts/fetch-map-assets.sh`), which downloads a pinned copy of Protomaps' fonts (about 6 MB, checksum verified, no `git` needed) into `~/Outpost/assets/fonts`.

Optional: CyberChef. An admin clicks **Install** on the Tools page (or runs `./scripts/fetch-cyberchef.sh`), which downloads [CyberChef](https://github.com/gchq/CyberChef) v11.5.0 (about 80 MB, checksum verified) into `~/Outpost/assets/cyberchef`. Outpost serves it at `/tools/cyberchef/`, behind the same sign-in, and links it from Tools.

Optional: Kolibri. An admin clicks **Install Kolibri** on the Education page (or runs `./scripts/install-kolibri.sh`), which installs [Kolibri](https://learningequality.org/kolibri/) 0.19.5 for the Education page, into `~/Outpost/kolibri-venv` with no administrator password. Kolibri needs Python 3.10 to 3.14; if the Mac has none (macOS's newest Python is often too new), the script installs Python 3.13 with Homebrew.

Shutdown in the top bar (admins, with a confirmation) stops Outpost cleanly; the login service restarts it only after a crash (`KeepAlive` with `SuccessfulExit` false), so it stays off. Double-click `Start Outpost.command` to start it again.

Run without the login service: `./scripts/setup-mac.sh --no-service`, then `./scripts/run.sh`.
Remove the service: `./scripts/uninstall-launchd.sh`. Logs: `~/Library/Logs/Outpost/outpost.log`.

## Settings

Stored in `~/.config/outpost/env` (see `.env.example`): `OUTPOST_HOME`, `OUTPOST_HOST`, `OUTPOST_PORT`, `OUTPOST_HTTPS` (`0` turns off the HTTPS listener), `OUTPOST_ALLOWED_HOSTS` (extra host names Outpost answers to, comma-separated), `OUTPOST_HTTPS_PORT` (default 8443), `OUTPOST_CONTENT_PORT` (default 8090) and `OUTPOST_CONTENT_HTTPS_PORT` (default 8453) for books, Education and apps, `OUTPOST_CAFFEINATE_BIN`, `OUTPOST_IOREG_BIN`, `OUTPOST_USER`, `OUTPOST_PASSWORD`, `OUTPOST_AI_PROVIDER`, `OUTPOST_AI_BASE_URL`, `OUTPOST_AI_API_KEY`, `OUTPOST_EMBED_MODEL`, `OUTPOST_RAG_MAX_CHUNKS`, `OUTPOST_PDF_MAX_MB`, `OUTPOST_KIWIX_BIN`, `OUTPOST_KIWIX_PORT`, `OUTPOST_KOLIBRI_PORT`, `OUTPOST_KOLIBRI_ZIP_PORT`, `OUTPOST_PMTILES_BIN`, `OUTPOST_CATALOG_URL`, `OUTPOST_COLLECTIONS_FILE` (your own curated list, same format as `data/collections.json`), `OUTPOST_APPS_FILE` (your own Apps shelf catalog, same format as `data/apps.json`), `OUTPOST_UPDATE_REPO` (the GitHub repository you install Outpost from, e.g. `you/outpost`, for the update checker), `OUTPOST_DOCKER` (`1` turns on Docker apps; the switch under Apps → Docker apps sets it), `OUTPOST_DOCKER_BIN`, `OUTPOST_OSRM_DIR`, `OUTPOST_OSRM_PROFILES`, `OUTPOST_OSMIUM_BIN`, `OUTPOST_GEOFABRIK_INDEX` (offline directions). `OLLAMA_URL` still works as the Ollama address.

### Using LM Studio or llama.cpp instead of Ollama

Any server with an OpenAI-style API works. Add to `~/.config/outpost/env`, then restart Outpost:

```sh
OUTPOST_AI_PROVIDER="openai-compatible"
OUTPOST_AI_BASE_URL="http://127.0.0.1:1234/v1"   # LM Studio; llama-server is usually http://127.0.0.1:8080/v1
OUTPOST_AI_API_KEY=""                            # only if your server asks for one
OUTPOST_EMBED_MODEL="text-embedding-nomic-embed-text-v1.5"   # an embedding model your server has, for document chat
```

- Download and remove models in the server itself; Outpost hides those buttons.
- The API key lives only in that file (readable by you alone). Outpost sends it to the server and never shows or logs it.
- llama-server runs one model. Start it with `-c 4096` (its default reserves the model's full context and can run out of memory) and, for document chat, `--embeddings --pooling mean` with `OUTPOST_EMBED_MODEL` set to the same model. Port 8080 clashes with Outpost, so pick another, e.g. `--port 8090`.
- Embedding models are recognised by name (`embed`, `bge`, `e5`, `gte`, `minilm`), because the OpenAI API doesn't say which models are which.

## Security and accounts

- Answers only to names this Mac really has: IP addresses, `localhost`, Bonjour `.local` names and the Mac's host name (add others with `OUTPOST_ALLOWED_HOSTS`). This stops DNS rebinding, where a web page points its own domain at your Mac so the browser treats Outpost as part of that page. Every response also forbids framing by other sites (`X-Frame-Options: SAMEORIGIN`, `frame-ancestors 'self'`), so no page can trick you into clicking Outpost's buttons.
- Books (`/kiwix`), Education (`/kolibri`) and apps (`/apps/<id>`) are served on their own port (8090, and 8453 for HTTPS; `OUTPOST_CONTENT_PORT`, `OUTPOST_CONTENT_HTTPS_PORT`), a different origin from Outpost itself. A script inside a book, an app or an uploaded file therefore can't read Outpost's pages or change anything in your name: the browser keeps the origins apart, and Outpost refuses changes whose Origin is the content port. The sign-in cookie is per host, so one sign-in covers both; only Outpost's own pages may frame the content (`frame-ancestors`). Old links on port 8080 are forwarded.
- The data folder (`~/Outpost`) is made readable by your Mac account only. Each person can keep up to 1,000 notes and 500 saved conversations. Saved installers are always served as downloads, never as pages.
- Listens on `127.0.0.1` only by default. Binding to another address requires a password: `OUTPOST_PASSWORD`, or at least one account (or `OUTPOST_ALLOW_OPEN=1` to override).
- Three modes. **Open** (no password, no accounts): everyone who can reach Outpost is an admin; fine on loopback. **Password**: `OUTPOST_USER`/`OUTPOST_PASSWORD` from the settings file is an admin who can always sign in. **Accounts**: Home → Accounts adds people as admins or members. Creating the first account (an admin) turns sign-in on and moves the notes and saved conversations written so far into it.
- Admins manage books, maps, AI models, documents, Education and accounts. Members read the library and maps, chat, and keep their own notes (`~/Outpost/notes/<name>/`) and saved conversations (`~/Outpost/chats/<name>/`); nobody sees anyone else's. The rule is enforced on the server: any change that isn't on the members' short list needs an admin, including routes added later.
- Accounts live in `~/Outpost/users.json` and sessions in `~/Outpost/sessions.json`, both readable by your user only. Passwords are hashed with scrypt; comparisons take constant time; five wrong passwords lock that name for 15 minutes (and twenty from one address). Sign-in sets an `HttpOnly; SameSite=Strict` cookie for 30 days; changes from other websites are refused. Basic auth still works for scripts. Removing an account keeps its notes and conversations on disk.
- Kolibri has its own accounts: add learners in Kolibri under Facility → Users. Outpost never passes its own sign-in on to Kolibri or the reader.
- When shared, Outpost also serves HTTPS on port 8443 with its own certificate authority, made on the Mac with the system's LibreSSL in `~/Outpost/tls` (keys readable by your user only). The CA is name-constrained to private IPv4 ranges (10/8, 172.16/12, 192.168/16, 127/8) and `.local`/`localhost`, so a phone that trusts it can't be fooled about real websites. The server certificate covers the Mac's current private addresses and its Bonjour name, lasts 825 days (Apple's limit), and is renewed when the addresses change. Phones set it up at `/join` (public, before sign-in), which offers `/outpost-ca.crt`; then Maps → Locate me uses the phone's GPS, offline. While locating, **Share with group** (opt-in each time, members included) sends your position at most every 10 seconds and at least every minute; everyone signed in sees who is sharing as named dots and a list with age and distance. Positions live in memory only (no disk, no history), one per account, and vanish on Stop, on leaving Maps, or after 15 minutes without an update. Verified end to end on an iPhone on 2026-10-31 (profile install, Certificate Trust Settings, trusted HTTPS, Locate me); Android follows the standard CA-certificate install but hasn't been tested yet. Home → Sharing shows a QR code for `/join` (made offline with `qrcode-generator`, MIT, bundled into `public/vendor/qr.js`) and the Mac's `.local` name, and an admin can tick **Keep this Mac awake while Outpost runs** (macOS `caffeinate -i -s -w <Outpost's pid>`, remembered across restarts; closing a laptop's lid still sleeps). The plain HTTP address still works; use either only on a network you trust.
- Browser checksum tools need `localhost` or HTTPS.

## How it works

- The document index holds up to 20,000 text parts in total (`OUTPOST_RAG_MAX_CHUNKS`). A part is about 750 characters of new text, so that is roughly 15 million characters, or a few dozen books. Search keeps every vector in memory: about 3 KB per part with `nomic-embed-text`, so 60 MB at the limit. On disk each part takes about 4 KB (vectors plus text). The Assistant page shows how much is used.
- Changing `OUTPOST_EMBED_MODEL` doesn't rebuild the index by itself. Documents indexed the old way stay searchable the old way (while that model is still installed) and are marked "needs re-indexing". **Re-index** runs in Transfers, saves after every batch of 16 parts, and continues where it stopped if cancelled or interrupted.
- The curated lists in `data/collections.json` name Kiwix books by name and flavour: five Wikipedia sizes, and six topics with three levels each, where a level includes the ones before it. Sizes are looked up live; books the catalog no longer has are left out and listed in the wizard, and a level that then adds nothing is hidden. Check the list with `npx tsx scripts/check-collections.ts` (all 60 books resolved on 2026-10-31).
- Library → Manage browses the whole Kiwix catalog by search, language, kind and size, shows which books you have (and when a newer edition of one is out), and pages through results. The catalog can't filter by size, so that filter applies to each page of results. A download that won't fit on the disk is refused before anything is written.
- Outpost runs Node with the macOS keychain's certificates (`NODE_USE_SYSTEM_CA=1` in `scripts/run.sh` and the npm scripts), so HTTPS works behind networks that inspect traffic with their own certificate authority. Without it, every download from the login service failed on such a network.
- Kolibri runs as a child of Outpost on `127.0.0.1:8082`, reached through Outpost at `/kolibri/` behind the same sign-in, with its data in `~/Outpost/kolibri`. Outpost turns off its network announcements (zeroconf) and restarts it at launch if it was running. Its interactive HTML5 activities load from a second private port (8083) so they stay sandboxed from the rest of Outpost; that works on this Mac, but other devices on your network can't open those activities. Kolibri keeps its own accounts: add learners in Kolibri under Facility → Users. Courses are imported in Kolibri from Kolibri Studio while online.
- Install buttons (admins): Education → **Install Kolibri** (or **Repair Kolibri**), Tools → CyberChef → **Install** and Maps → **Install map fonts** run `scripts/install-kolibri.sh`, `scripts/fetch-cyberchef.sh` or `scripts/fetch-map-assets.sh` from the Outpost folder as a job in Transfers, only after the admin confirms the exact command in the same dialog as the Apps shelf (`src/services/installers.ts`, `/api/install/:id`). The script gets `OUTPOST_HOME` and runs without a shell in its own process group, so Cancel also stops its download; a second click joins the install in progress, a failure shows the script's own `Error:` line, and curl's progress bar shows as a percentage. Both scripts stay usable from Terminal and give the same result.
- Directions (Maps → Directions): turn-by-turn routes by car, on foot or by bike on Outpost's own map, worked out on the Mac by OSRM 26.10.0 (`brew install osrm-backend`, BSD-2-Clause) with no internet. A map's `.pmtiles` only draws roads, so an admin adds directions per map once, online: Outpost reads Geofabrik's region list (`index-v1.json`, kept a week in `~/Outpost/routing`), works out which regions cover the map (for a grid of points over the map, the smallest region holding each; continents only when no country covers it, since map edges are often sea), shows each one's size, downloads the ticked ones, joins and cuts them to the map's area plus 0.05° with osmium 1.19.1 (`brew install osmium-tool`, GPL-3.0, run as a separate program), then prepares OSRM's car, foot and bicycle profiles (MLD) in `~/Outpost/routing/<map>/`. The profiles are wrapped to prefer `name:en` road names, since the instructions are written in English by Outpost (`describeStep` in `src/services/routing.ts`). On this Mac (M3 Pro) Lebanon + Syria + Israel and Palestine (244 MB of downloads) took about 3½ minutes, mostly downloading, and uses 1.3 GB; Lebanon alone prepares in about 30 seconds. `osrm-routed` runs per map and mode on a free port on 127.0.0.1, started on the first request and stopped after 15 quiet minutes (about 200 MB of memory each for Lebanon); routes come back in milliseconds. Everyone signed in can ask for routes (`GET /api/routing/<map>/route?mode=car|foot|bike&from=lon,lat&to=lon,lat`); looking up regions (it goes online), preparing and removing need an admin. New data replaces the old only once complete. OSRM data only works with the version that made it (OSRM releases monthly), so when Homebrew updates OSRM, Outpost prepares the data again at startup from the road data it kept, with no download. Directions can start from Locate me, a place search or a tap on the map, and go to a place, a tap, someone on the group map, or an SOS alert. Road data © OpenStreetMap contributors (ODbL). No traffic, and routes are only as good as OpenStreetMap's roads there.
- Map search finds places (cities, towns, villages, neighbourhoods), not street addresses. When a map is added, Outpost scans its `places` layer up to zoom 13 in the background (shown in Transfers) and keeps the places inside the map's area in `~/Outpost/maps/<file>.places.json`. Lebanon at zoom 13 (20 MB) gave 2,674 places in under a second. Search ignores accents and case, tolerates small typos, and also matches names in other languages; results show the English name next to the local one. The very smallest places, which the map only shows from zoom 14, aren't indexed.
- Tools → Calculator and Unit converter run entirely in the page, offline. The calculator (`public/js/calc-engine.js`) parses expressions itself, never with `eval`: usual operator order, brackets (a missing closing one at the end is fine), powers right to left, `!` and `%` (where `a + b%` means a plus b percent of a), implied multiplication (`2π`, `3(4+1)`), degrees or radians, `Ans`, and only its own function and constant names. Answers keep 12 significant digits, with floating-point noise rounded away (0.1 + 0.2 = 0.3, sin 180° = 0), and errors are explained in words. Standard and Scientific modes, keyboard input, a live preview, and the last 20 calculations are remembered per device. The converter (`public/js/units.js`) covers length, area (including the dunam), volume, weight, temperature, speed, time, pressure, energy, power, data, angle and fuel economy, with exact definitions (international inch, pound and gallon; NIST SP 811); either box can be typed in, amounts may be sums like `3×12`, and every unit of the measure is listed at once. No currency, which would need the internet.
- Tools → Benchmark times this Mac: SHA-256 and zlib on one core, SHA-256 on all cores, memory copy, disk write and read on the drive that holds `~/Outpost` (1 GB, with the memory cache bypassed through macOS's `F_NOCACHE` via the built-in Perl), and AI tokens per second with the configured server and a fixed prompt after a warm-up. Each figure is compared with round reference numbers in `src/services/benchmark.ts` (matching them scores 1000), and the four categories are combined with a geometric mean. History is kept in `~/Outpost/benchmarks.json`; nothing is uploaded. An M3 Pro with llama3.2:3b scored 1327 and 1301 on two runs (about 9 seconds each). AI tokens are counted as streamed pieces, which is one token per piece on Ollama and llama.cpp. Scores vary with what else the Mac is doing (a run with a browser busy alongside scored 1173).
- Builder Tag: an optional display name and hardware label (default: the chip and memory read from `sysctl`, e.g. "Apple M3 Pro · 18 GB"), saved in `~/Outpost/state.json` and copied into each result when it runs. Any result can be exported as JSON or saved as a 1200×630 PNG card drawn in the browser. Nothing is uploaded and there is no account; sharing is up to you.
- Update checks are off until an admin turns them on (Tools → Updates); while off, Outpost contacts nothing. When on, once a day it asks GitHub for the latest release of `OUTPOST_UPDATE_REPO` (skipped, with a note, if unset), the Kiwix catalog for newer editions of installed books (files named like the catalog's, `<name>[_<flavour>]_<YYYY-MM>.zim`), and Ollama's registry for newer versions of installed models (a model's local digest is the SHA-256 of its registry manifest). It sends no identifiers. Each update has a Download button; new book editions download next to the old ones, models update through Ollama, and Outpost never updates itself or deletes anything.
- Menu: the sidebar lists every main page under four headings (Know: Library, Education, Documents; Ask and find: Assistant, Maps; Be ready: Preparedness, Radio, Voice; Keep: Notes, Tools, Apps, Games), with Emergency as a red SOS bar above them; it scrolls on very short screens, and the map-route picture above Transfers hides below 880 px of height. On phones it becomes a bottom bar of Home, Library, Chat, Maps, SOS and More; More slides up every section under the same headings, plus Transfers (a red dot on More while something runs) and Account (`public/js/menu.js`, built from the sidebar so the two stay in step).
- Emergency (the red SOS bar at the top of the menu, the red SOS tab on phones, and a red strip at the top of Home, with the green Voice band under it): Signal (one-tap SOS as sound and full-screen light, Morse sender and reader with keying, NATO spelling, a radio channel card); First aid (five short cards, CPR for an adult (hands only), severe bleeding, making water safe, hypothermia and heat stroke, each written in plain words from a named government page (Seattle Fire and Emergency Management, CDC, NIOSH) with the date checked, plus a CPR beat that beeps and flashes at 110 a minute with a push counter and timer, and a "Read more offline" link into WikiMed when that book is installed; they don't replace training, and choking and burns aren't included yet); My card (contacts, blood type, allergies, conditions, medicines and meeting points, kept per person in `~/Outpost/emergency/<name>.json`, readable by your Mac account only, printable as a card); Kits (go-bag, home and car checklists based on Ready.gov (FEMA) kit lists, with your own items, and a water and food calculator using at least 3.8 litres, 1 US gallon, per person per day). Location (type coordinates in decimal, degrees-minutes-seconds, UTM or MGRS, or a place name found on your offline map, or use the map's last centre; see every format in large type, MGRS spelled for radio, and sunrise, sunset and civil twilight for any date by NOAA's method, all offline). Coordinates are checked against the `mgrs` library on 3,000 points and sun times against `suncalc` (both test-only dependencies). For a phone's own GPS position, use Locate me on Maps over HTTPS. Every tab prints cleanly.
- Network SOS (Home's red strip → **Send SOS**, or Emergency → Signal): asks first, with an optional message (up to 280 characters) and the sender's position when the device knows it (from Locate me in the last 10 minutes, or asked for in the dialog over HTTPS). Every signed-in page checks `/api/sos` every 4 seconds and shows active alerts as a terracotta banner on top of every page (name, message, time, distance when both positions are known, **Show on map**, **I'm coming**), with a two-tone Web Audio alarm and vibration until silenced or answered; browsers only play sound after the page has been touched once, and the banner says so. The sender sees who is coming and can cancel; an admin can cancel any. Members can send, answer and cancel their own (listed in the member gate in `src/auth.ts`); one alert per person per 30 seconds. Alerts live in memory only (no disk, no history) and end after 2 hours. It reaches people on this Outpost only, not emergency services.
- Voice messages (Be ready → Voice, the green Voice band under SOS on Home, and the mic button on every other page): one shared channel for everyone signed in. Tap the mic button (or **Turn on voice**) once to allow the microphone; that same tap starts the page's audio, which Safari and iPhones require before a page may play sound on its own. Then hold to talk (or the space bar on any page): chirps mark start and stop, up to 60 seconds, slide off to cancel. The browser records 16 kHz mono 16-bit WAV itself with an AudioWorklet (`public/js/wav.js`, `voice-worklet.js`), so every phone and computer can play every clip with no converter. Outpost (`src/services/voice.ts`, `/api/voice`) accepts only that format, 0.3–60 s, one clip per 2 s per person; keeps clips in `~/Outpost/voice` (owner-only) with an index that survives restarts, and deletes them after 24 hours; the sender or an admin can delete one. Devices check every 3 s (`public/js/voice-core.js`, app-wide): new messages from others play one after another after an incoming chirp while voice is on and not muted, and otherwise wait marked New, with red counts on the mic button, Voice in the menu and More. "Mine" is per device, not per account, so your iPhone's messages play on your Mac. If the browser pauses sound (an iPhone app back from the background), messages wait and the mic button shows an amber ring until the next tap anywhere. The Voice page shows who is on the channel now (from those 3-second checks, in memory only): each person, their devices, and how many are listening.
- Apps (Home → Apps): local web apps Outpost installs, starts and stops for you. It ships with File Browser 2.63.23 (Apache-2.0), installed from its official GitHub release for your chip, checked against a SHA-256 pinned in `data/apps.json` and unpacked into `~/Outpost/bin` (Homebrew's build has no web pages: it's built from source, where File Browser's web interface isn't included). It serves `~/Outpost/files` at `/apps/files/` behind Outpost's sign-in (it runs with `--noauth`, so there is no second login); members can browse and download, only admins can upload, rename or delete. Nothing runs until an admin confirms a dialog showing the exact command, and the server refuses to run anything other than the command that was shown. Apps listen on `127.0.0.1` only. Also on the shelf: Navidrome 0.64.2 (GPL-3.0, official release, SHA-256 pinned), a music and audiobook player for the `Music` folder of File Browser, at `/apps/music/` with its own accounts (the first visitor creates its admin). Running apps start again when Outpost restarts. Admins can add their own app with a start command (split like a shell would, but never run through one), a port and an optional ready check; apps that take a base path are served at `/apps/<short name>/`, others are linked at `localhost:<port>`, which only this Mac can open. Custom apps are kept in `~/Outpost/apps.json` (readable by your Mac account only). To add an app for everyone, add an entry to `data/apps.json`: `install` (a command) or `download` (an archive URL and SHA-256 per chip, and the one file to unpack) and `args` are argument lists or objects as in the File Browser entry, and `args` and `folders` may use `{port}`, `{prefix}` (`/apps/<id>`), `{data}` (`~/Outpost/apps/<id>`) and `{home}`.
- Docker apps (Apps → Docker apps, admins only, reads included): off unless `OUTPOST_DOCKER=1`; admins turn it on or off with the switch on that page, which saves the setting to the settings file (owner-only) and restarts Outpost under launchd, or asks for a manual restart otherwise. Outpost finds the `docker` command on the PATH or where Docker Desktop (`~/.docker/bin`, `/Applications/Docker.app/Contents/Resources/bin`) or OrbStack (`~/.orbstack/bin`) put it; without one it shows links to both and changes nothing, and it says so when the engine isn't running. The form takes only an image, a short name, the app's port, a port on this Mac, settings (environment variables) and folders; any other field (`privileged`, `network`, `capAdd`, `volumes`…) is refused with the reason. Outpost builds the whole `docker run --detach --name outpost-<name> --label com.outpost.managed=true --restart unless-stopped --publish 127.0.0.1:<port>:<port> --env … --mount type=bind,source=~/Outpost/containers/<name>/<folder>,target=…[,readonly] <image>` itself, shows it in the same confirmation dialog as the Apps shelf, and runs it only if the confirmed text is exactly what it would run, with `execFile` and an argument list (no shell), as a job in Transfers (the image may download first). Folders must be inside `~/Outpost/containers/<name>/` (no `..`, no Mac paths, and links that lead out are caught after resolving them); nothing may go over `/`, `/proc`, `/sys`, `/dev`, `/etc` or `/run` in the container, and anything mentioning `docker.sock` is refused. The finished arguments are checked once more for `--privileged`, `--network`, `--cap-add`, `--device` and the like before running. The list, start, stop, messages (`docker logs --tail 200`) and remove act only on containers that carry Outpost's label and name prefix; others on the Mac aren't shown or touched. Removing deletes the container and keeps its folder. Apps open on this Mac only (`localhost:<port>`). Before showing the command and again before running it, Outpost checks that the port on this Mac is free and says so plainly if not; if `docker run` still fails part way (Docker makes the container, then can't start it), Outpost removes that unstarted container, only when it carries Outpost's label. Verified against OrbStack (Docker 29.8.2) on macOS 27.2: run from the form, list, stop, start, messages, remove, read-only and writable folders, settings, the 127.0.0.1-only port, a port clash, and other containers left alone; the tests use a stand-in `docker` (`test/fixtures/fake-docker.mjs`).
- Apps → Get for your devices: a catalog of offline apps for phones and computers (Organic Maps with turn-by-turn directions, Kiwix, KeePassXC, Stirling PDF, Bitchat, Meshtastic, VLC, LibreOffice) with links to each official page. An admin can save an installer (Android `.apk` or Mac `.dmg`) after confirming the exact download; Outpost keeps it only if its SHA-256 matches the one GitHub publishes for that release, and puts it in `~/Outpost/files/Installers`. Any signed-in device can then download it from `/installers/<file>` with no internet. The catalog lives in `data/apps.json` (`devices`), checked 2026-10-31.
- Downloads run two at a time; the rest show as "Waiting" in Transfers. Model downloads started from the wizard run on the server, so they continue if you close the page.
- Live GPU gauge (Assistant page, everyone signed in): once a second while the page is visible, Outpost reads `ioreg -r -d 1 -w 0 -c IOAccelerator` (macOS's own GPU statistics: "Device Utilization %", "In use system memory", the chip and its GPU core count; no administrator rights, unlike `powermetrics`) and, with Ollama, `/api/ps` (which model is in memory and how much of it is on the GPU). One reading serves every open page (`GET /api/ai/gpu`, at most about once a second). It shows a dial, GPU memory against the Mac's shared memory, the last minute as a line, and e.g. "llama3.2:3b in memory: 2.2 GB, all on the GPU". The percentage counts all GPU work on the Mac (the screen and other apps too): on an M3 Pro it sat around 25–45% idle and 94–98% while llama3.2:3b answered. Intel Macs and other systems that don't report it get a note instead of a gauge.
- Tested providers: Ollama 0.40.12 (both its own API and its `/v1` OpenAI API) and llama.cpp `llama-server` 0.8.0. LM Studio speaks the same API but has not been run here.
- Document chat reads PDF, text, Markdown, CSV, JSON and HTML. PDF text is extracted on this Mac with Mozilla's PDF.js (via `unpdf`). Scanned PDFs have no text layer and are refused with a message; Outpost does no OCR. PDFs over 50 MB are refused (`OUTPOST_PDF_MAX_MB`).
- `kiwix-serve` comes from the official macOS build at download.kiwix.org. Homebrew has no kiwix-tools formula, so if that download fails, put `kiwix-serve` in `~/Outpost/bin` yourself.
- The model list hides embedding-only models (such as `nomic-embed-text`) from the chat picker. That relies on Ollama reporting model capabilities (0.6 and later) or a BERT model family.

## Known limits

- Verified on macOS 27.2 on an Apple Silicon Mac (M3 Pro) with kiwix-tools 3.8.2, Ollama 0.40.12 (and a fresh install with 0.40.16) and the Homebrew pmtiles build. Intel Macs have not been tested. Setup fetches kiwix-tools 3.8.2 from official Kiwix mirrors first (checked by SHA-256), because download.kiwix.org can be very slow from some networks.
- Phones: the HTTPS setup, Locate me and adding Outpost to the home screen were verified on an iPhone (after turning on the certificate in Certificate Trust Settings, which the join page now checks); Android follows the standard certificate install and app install but hasn't been tested.
- Docker apps were verified with OrbStack, not yet with Docker Desktop.
- Network SOS: a phone only rings while Outpost is open on screen and has been tapped once; a locked phone or closed tab doesn't ring.
- Voice messages: like SOS, a phone only plays them while Outpost is open on screen, and needs one tap on the mic button each time the app is opened (a browser rule for the microphone and sound). Missed messages wait, marked New. Messages, not live talk: a second or so after letting go.
- Directions are in English, with no live traffic, and only as good as OpenStreetMap's roads in your area.
- Apps: Outpost can't check that a custom app listens on `127.0.0.1` only; that's up to its command. File Browser's own port (`127.0.0.1:8095`) has no login, so any program on this Mac can reach it. Removing an app from the shelf doesn't uninstall it (File Browser is `~/Outpost/bin/filebrowser`) or delete its files (`~/Outpost/files`, `~/Outpost/apps/<id>`). Catalog versions are pinned: newer releases don't appear until `data/apps.json` is updated (the update checker doesn't cover apps). Phone music apps that use Navidrome's Subsonic API can't sign in through Outpost; use Navidrome in the browser. iPhones only install from the App Store, so the catalog gives them links. Saved installers count toward the storage on Home.
